# Redis Lite Python
A lightweight Redis-like key–value store written in Python.

This project simulates core Redis behaviors (SET/GET/DEL, TTL, in-memory storage, pub/sub optional, etc.) for learning, testing, and experimentation—without needing a running Redis server.

## 🚀 Features

- 🗃️ In-memory key–value storage

- ⏱️ TTL support (expiration system similar to Redis)

- 🔁 Atomic operations (like INCR, DECR)

- 📦 Lists, Sets, and Hash-like structures

- 🔔 Optional Pub/Sub mechanism

- 📝 Pluggable storage engine interface

- 🧪 Perfect for local testing, teaching, or prototyping without Redis
